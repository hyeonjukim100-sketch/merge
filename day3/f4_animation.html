배열 [10, 20, 30]을 하나씩 꺼내 3배로 만든 뒤 모두 더하는 코드입니다. “다음 단계”를 눌러 한 줄씩 따라가 보세요.

코드 (노란 줄 = 지금 실행 중)

const f=(i) => i*3
let arr =[10,20,30]
let sum=0
for (const v of arr) {
    console.log('v=' + v)
    sum = sum + f(v)
}
console.log(sum)
