2

LLM과 데이터 늘리기

기본 예제에는 데이터가 2개만 들어 있습니다. 직접 제주 관련 데이터를 수집하여 총 50~100개로 늘려 보세요.

  • 추가할 데이터의 개수와 항목은 학생이 직접 결정
  • Claude Chat 모드를 활용해 자료 조사 및 JSON 작성 가능
  • category는 같은 표현으로 통일 (예: 해변 / 해수욕장 섞지 않기)
  • 중복 데이터가 없는지 직접 확인
  • 완성한 데이터를 JSON 파일로 저장
3

데이터로 사이트 만들기

2단계에서 만든 데이터를 활용해 자유롭게 사이트를 만들어 보세요.

프롬프트 예시

  • 첨부한 JSON 데이터로 제주 소개 웹페이지를 만들어 줘. 항목을 카드 형태로 보여 줘.
  • category별로 버튼을 만들고, 누르면 해당 항목만 보이게 해 줘.
  • selected가 true인 항목만 모아서 "가 보고 싶은 곳" 목록을 만들어 줘.
  • score가 높은 순으로 정렬하고, 이름으로 검색할 수 있게 해 줘.
4

GitHub에 배포

완성한 사이트를 GitHub에 올려 배포합니다.

저장소 이름 예: jeju_foods_project

5

Vercel에서 배포

Vercel에 GitHub 계정으로 로그인한 뒤, 4단계 저장소를 Import하여 배포합니다.

6

강사님께 링크 공유

배포된 사이트 주소(https://….vercel.app)를 강사님께 공유합니다.
